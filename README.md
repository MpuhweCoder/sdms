# Student Data Management System (SDMS)

A Laravel-based Student Data Management System built for managing student records with full CRUD functionality, search, sorting, and pagination.



## Features

- Add new students
- View all students
- Edit student details
- Delete student records
- Search students
- Pagination support
- Sort students by different fields
- Clean UI using Blade templates
- Laravel MVC architecture


## Tech Stack

- PHP 8.4
- Laravel 13
- SQLite / MySQL
- Blade Templates
- Bootstrap / Custom CSS
- Git & GitHub



## Project Structure

### Branch Workflow

| Branch | Purpose |
|---|---|
| `main` | Stable production branch |
| `develop` | Main development branch |
| `database-config` | Database setup & migrations |
| `student-model-controller` | Student model and controller |
| `add-student` | Add student functionality |
| `view-students` | Display student records |
| `edit-student` | Edit and update students |
| `delete-student` | Delete student functionality |
| `search-pagination` | Search, sorting & pagination |
| `feature/student-crud` | Combined CRUD feature branch |
